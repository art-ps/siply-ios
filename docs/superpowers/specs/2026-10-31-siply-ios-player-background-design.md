# Siply для iPhone — живой фон плеера

## Зачем

Полноэкранный «Сейчас играет» сейчас — системный белый/чёрный лист с обложкой посередине. Хочется современно: фон, который медленно переливается цветами обложки и чуть «дышит» под громкость трека. Как у Apple Music, но живое.

## Решено с пользователем

- Вариант **2**: mesh-градиент из цветов обложки с медленным дрейфом + пульс по громкости.
- **Только полноэкранный плеер** (`NowPlayingSheet`). Мини-плеер, списки папок и треков, поиск — не трогаем.

## Что делаем

### 1. Палитра из обложки

`ArtworkPalette.colors(from data: Data?) -> [Color]` — ровно 9 цветов для сетки 3×3, построчно.

- Есть обложка: декодируем `UIImage`, рисуем в `CGContext` 3×3 пикселя (RGB, 8 бит, без альфы) — CoreGraphics сам усредняет; читаем 9 пикселей. Каждый переводим в HSB и правим: насыщенность `max(s, 0.35)` (пиксели с насыщенностью `< 0.1`, то есть ч/б обложки, берут оттенок и насыщенность акцента), яркость зажимаем в `0.18…0.45`. Тёмный фон — белый текст читается на любой обложке.
- Нет обложки или данные не декодируются: 9 оттенков акцента `#6B85A3` — тон `hue ± 0.04` по сетке, яркость `0.2…0.4`, насыщенность как у акцента. Детерминированно: один и тот же вход — та же палитра.
- Без Vision и CoreImage. Функция чистая, вызывается из `Task.detached` при смене трека.

### 2. Громкость из движка

- `AudioEngine` получает `var level: Float { get }` — текущая громкость `0…1`; `0`, если ничего не загружено или пауза.
- `AVAudioPlayerEngine`: при `load` включает `isMeteringEnabled = true`; геттер `level` зовёт `updateMeters()` и переводит `averagePower(forChannel: 0)` (дБ) в `0…1` линейно на отрезке `-60…0` дБ, вне отрезка — зажим. Перевод вынесен в `static func normalized(db: Float) -> Float` — чтобы тестировался без звука.
- `PlayerModel.level: Float` (вычисляемое): `isPlaying ? engine.level : 0`. Не observable: вид опрашивает сам.
- `FakeAudioEngine.level` — обычное поле.

### 3. Вид фона `PlayerBackground`

`PlayerBackground(colors: [Color], level: () -> Float)`.

- `TimelineView(.animation(paused: reduceMotion))` → `MeshGradient(width: 3, height: 3, points:, colors:)`.
- Дрейф точек: `static func points(at t: Double, amplitude: Float) -> [SIMD2<Float>]`. Углы неподвижны; середины рёбер двигаются только вдоль своего ребра; центр — по обеим осям. Смещение `amplitude * sin(t * ω_i + φ_i)`, `ω_i` — своя у каждой подвижной точки в диапазоне `2π/8…2π/14` (цикл 8–14 с), `φ_i` — фиксированные фазы. Все координаты в `0…1`.
- Пульс: уровень сглаживается `s = s * 0.85 + level * 0.15` на каждом кадре (без рывков). Амплитуда дрейфа `0.08 + 0.06 * s`; яркость цветов умножается на `1 + 0.25 * s` (через `.brightness`-подобную правку HSB или `overlay` белого с `opacity 0.12 * s` — решает исполнитель, второе проще). Пауза → `level = 0` → только дрейф.
- `@Environment(\.accessibilityReduceMotion)` = true → таймлайн на паузе, `t = 0`, пульс не применяется. Статичный градиент.

### 4. Встраивание в `NowPlayingSheet`

- `.presentationBackground { PlayerBackground(...) }` — фон на весь лист, включая safe area.
- `.environment(\.colorScheme, .dark)` на содержимом листа: текст, слайдер, кнопки — светлые, как у Apple Music, независимо от темы системы. `.secondary` остаётся системным — на тёмном он светло-серый.
- Палитра: `@State private var colors: [Color]`, пересчёт в `.task(id: track?.artwork)` через `Task.detached`. Пока не посчитана — палитра для «нет обложки» (не белый экран).
- Кнопка скорости `.bordered` и `RoutePicker` — проверить на тёмном, подправить `tint` если сливаются.

## Критерии приёмки (тесты)

- `ArtworkPaletteTests`
  - `solidRedArtwork_keepsHueDarkensBrightness`: PNG 8×8 чистого `#FF0000` → 9 цветов, у всех hue ≈ 0 (±0.02), brightness в `0.18…0.45`, saturation ≥ 0.35.
  - `nilArtwork_accentPalette`: `nil` → 9 цветов, hue в пределах `hue(#6B85A3) ± 0.04`, brightness в `0.2…0.4`.
  - `garbageData_accentPalette`: `Data([1,2,3])` → то же, что `nil`.
  - `sameInput_sameOutput`: два вызова с одним PNG дают равные массивы.
- `AVAudioPlayerEngineTests`
  - `normalized(db:)`: `-60 → 0`, `0 → 1`, `-30 → 0.5`, `-160 → 0`, `+10 → 1`.
- `PlayerModelTests`
  - `level_zeroWhenPaused`: `FakeAudioEngine.level = 0.7`, пауза → `player.level == 0`.
  - `level_passesThroughWhenPlaying`: играет → `player.level == 0.7`.
- `PlayerBackgroundTests`
  - `points_cornersFixed`: при любом `t` углы ровно `(0,0) (1,0) (0,1) (1,1)`.
  - `points_edgesStayOnEdges`: у середин рёбер фиксированная координата не меняется.
  - `points_inUnitSquare_andMove`: все в `0…1`; `points(at: 0) != points(at: 3)`.
- Ручная проверка (чеклист, пункт 15): открыть плеер на треке с цветной обложкой → фон в её цветах, медленно переливается; на громком месте чуть ярче; пауза → переливается, не пульсирует; трек без обложки → серо-голубой фон; «Уменьшение движения» в настройках iOS → фон стоит; светлая тема системы → текст в плеере белый, читается.

## Не делаем

- Тумблер «живой фон» в приложении — его нет; выключатель — системное «Уменьшение движения».
- Спектр/эквалайзер (`AVAudioEngine` с tap) — отдельный проект, если пульса окажется мало.
- Фон за мини-плеером, списками, поиском.
- Анимация перехода палитры между треками: цвета меняются сразу. Если резко — `.animation(.easeInOut(duration: 1), value: colors)` одной строкой, не в этой спеке.
