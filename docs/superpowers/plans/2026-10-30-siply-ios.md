# Siply для iPhone — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iPhone-версия Siply: список источников (своя папка + папки из Files), экран папки с треками, мини-плеер над табами, поиск по именам, фон/локскрин — собирается и ставится на iPhone через Xcode.

**Architecture:** Новый репо `~/projects/siply-ios`, SwiftUI + AVFoundation без зависимостей. UI: `TabView` «Папки»/«Поиск», `tabViewBottomAccessory` — мини-плеер, sheet «Сейчас играет».

**Tech Stack:** Swift 5, SwiftUI, AVFoundation, MediaPlayer, XcodeGen 2.46, Xcode 27.2, iOS 26.1+, XCTest на симуляторе.
