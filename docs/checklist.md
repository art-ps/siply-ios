# Ручная проверка на iPhone

Отмечайте перед каждой сборкой в TestFlight.

1. Заблокировал экран — играет; локскрин показывает обложку и кнопки; AirPods вытащил — пауза.
2. Папка iCloud с нескачанными треками: серые с ☁︎, тап — скачал и заиграл; следующий серый в очереди докачался сам.
3. Флешка вытащена → источник серый «Не подключена»; вставил → снова рабочий без перезапуска.
4. Finder на Маке → iPhone → Files → Siply: скопированная папка появляется в источнике «Siply» после pull-to-refresh или повторного входа.
5. Мини-плеер над табами, сворачивается при скролле, без пустой полоски когда ничего не играет.
6. Входящий звонок во время игры → пауза, после звонка играет дальше.
7. Файл `.flac` из Files → Поделиться → Siply: играет; если лежит в источнике — очередь из папки.
8. Папка по SMB / из Яндекс.Диска (Files → провайдер): треки видны по именам файлов, тап → индикатор → играет, после — теги и обложка.
9. Флешка вытащена при открытом приложении → источник серый; вставил → pull-to-refresh или свернуть/развернуть → снова рабочий.
14. Скорость 1,25× — речь быстрее, тон тот же; локскрин показывает прогресс верно; после перезапуска 1,25× осталась.
